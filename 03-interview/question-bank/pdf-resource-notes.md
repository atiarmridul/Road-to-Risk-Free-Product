## Deduplicated practice groups

Instead of repeating similar questions, prepare one strong answer for each group:

1. QA vs QC, verification vs validation, and testing principles
2. Testing levels, types, and when to use each
3. Test scenario, test case, test plan, and test strategy
4. Severity, priority, defect lifecycle, and defect advocacy
5. Agile ceremonies and QA contribution throughout a sprint
6. Risk-based testing under time or resource constraints
7. API, database, automation, performance, security, and mobile depth
8. Leadership, conflict, mentoring, estimation, and stakeholder communication
9. Release readiness, production incidents, and continuous improvement

For prepared answers, use the [scenario question bank](senior-qa-interview-questions.md) and [readiness checklist](../interview-readiness-checklist.md).
