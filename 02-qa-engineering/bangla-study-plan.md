# QA ইঞ্জিনিয়ারিং (অ্যাডভান্সড): বাংলা স্টাডি প্ল্যান

## উদ্দেশ্য

এই নোট `02-qa-engineering` মডিউল থেকে mid-senior থেকে senior mindset তৈরি করতে সাহায্য করবে।

## ১০ দিনের ফোকাস প্ল্যান

1. দিন ১: Test Strategy Planning
2. দিন ২: Quality Gate & Release Readiness
3. দিন ৩: Defect Management & Quality Metrics
4. দিন ৪: Test Data & Environment Management
5. দিন ৫: Flaky Test Management
6. দিন ৬: API Reliability & Performance ভাবনা
7. দিন ৭: Security Testing for QA
8. দিন ৮: Playwright UI Automation strategy
9. দিন ৯: Risk-based roadmap + prioritization
10. দিন ১০: Mock release decision meeting

## Senior QA চিন্তার ফ্রেমওয়ার্ক

- Risk first, test later
- Business impact অনুযায়ী prioritization
- Pass/fail report না, decision-ready insight
- Team enablement: dev + qa + product alignment

## Must-have ডকুমেন্ট প্র্যাকটিস

- test strategy one-pager
- release exit criteria checklist
- defect triage guideline
- flaky test RCA template
- test environment health checklist

## Interview প্রশ্ন (Senior level)

1. কোন metrics দেখে release block করবেন?
2. Flaky tests বেশি হলে team-level action plan কী?
3. Regression scope কীভাবে risk-based করবেন?
4. Security testing responsibility QA টিমে কীভাবে define করবেন?
5. Test strategy আর test plan-এর relation কী?

## Hands-on Scenario

একটি e-commerce release-এর জন্য:

- top 5 critical user flow identify করুন
- quality gate লিখুন (must pass, should pass)
- rollback criteria define করুন
- post-release monitoring plan লিখুন
