## Maintenance rule

Before adding another resource:

1. Check whether its concepts already exist in a canonical Markdown note.
2. Store the original only when it adds lasting reference value.
3. Add a concise synthesis or routing entry in the relevant topic folder.
4. Record image-only documents as requiring OCR or visual review.
5. Do not commit multiple copies of the same file.
