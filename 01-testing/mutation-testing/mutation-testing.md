# Mutation Testing Learning Guide

Mutation testing makes small deliberate changes to production code and checks whether the test suite catches them. A surviving mutation may reveal a weak assertion or an untested behavior.

## Learning order

1. [Foundations](foundations.md)
2. [Infection with PHP](infection-php.md)
3. [Stryker with JavaScript](stryker-javascript.md)
4. [Decision guide](decision-guide.md)

Code coverage asks whether a line ran. Mutation testing asks whether the tests would notice if that line behaved incorrectly.
