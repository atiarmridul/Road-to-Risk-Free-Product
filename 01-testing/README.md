# Testing Learning Hub

Testing is the process of gathering evidence about product quality and risk. Start with the foundations, then move from small code-level tests toward complete user journeys.

## Recommended learning order

1. [Testing foundations](testing-foundations.md)
2. [Unit testing](unit-testing/unit-testing.md)
3. [Mocking and stubbing](mocking-stubbing/mocking-stubbing.md)
4. [Test-driven development](tdd/tdd.md)
5. [Integration testing](integration-testing/integration-testing.md)
6. [Contract testing](contract-testing/contract-testing.md)
7. [End-to-end testing](e2e-end-to-end-testing/e2e-end-to-end-testing.md)
8. [Test coverage](test-coverage/test-coverage.md)
9. [Mutation testing](mutation-testing/mutation-testing.md)
10. [Visual regression testing](visual-regression-testing-ui/visual-regression-testing-ui.md)
11. [Performance testing](performance-testing/performance-testing.md)

## Interview shortcut

If time is short, study foundations, unit testing, integration testing, E2E testing, mocking, and coverage first. For every test level, be ready to explain what it checks, what it does not check, one example, and one trade-off.
