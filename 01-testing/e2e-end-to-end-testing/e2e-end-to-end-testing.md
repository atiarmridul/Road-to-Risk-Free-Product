# End-to-End Testing Learning Guide

End-to-end testing follows a complete user journey through the real application stack.

## Recommended learning order

1. [Foundations](foundations.md) — purpose, scope, and pyramid placement
2. [Cypress](cypress-guide.md) — browser-test examples and workflow
3. [Playwright](playwright-guide.md) — cross-browser examples and tooling
4. [Laravel Dusk](laravel-dusk-guide.md) — Laravel browser testing
5. [Core scenarios](core-scenarios.md) — login, checkout, forms, uploads, and real-time flows
6. [Advanced scenarios](advanced-scenarios.md) — multi-user, visual, mocked, mobile, and accessible flows
7. [Execution and CI](advanced-execution.md) — pipelines and advanced operation
8. [Best practices](best-practices-and-review.md) — trade-offs, anti-patterns, and revision

## Beginner mental model

An E2E test is like a student completing the whole school journey: entering, attending class, submitting work, and receiving a result.
