# WebdriverIO Learning Hub

WebdriverIO is a Node.js automation framework for browser and mobile testing. It supports WebDriver and WebDriver BiDi, runner integrations, services, reporters, and Appium workflows.

## Prerequisites

- [JavaScript and TypeScript](../../02-programming/javascript-typescript/README.md)
- [Shared automation concepts](../../03-shared-concepts/README.md)

## Learning order

1. [Setup and first test](setup-and-first-test.md)
2. [Selectors, waits, and assertions](selectors-waits-and-assertions.md)
3. [Configuration and capabilities](configuration-and-capabilities.md)
4. [Runner, services, and hooks](runner-services-and-hooks.md)
5. [Framework design and reporting](framework-and-reporting.md)
6. [Appium integration](appium-integration.md)
7. [WebdriverIO exercises](../../05-practice/webdriverio-exercises.md)

Use the [interview review](../../07-reference/webdriverio-interview-review.md) only after you can implement and debug the concepts.

## Completion checkpoint

Build a small WebdriverIO suite with isolated data, condition-based waits, meaningful assertions, failure screenshots, and a CI command. Explain the role of capabilities, services, hooks, and the selected automation protocol.
