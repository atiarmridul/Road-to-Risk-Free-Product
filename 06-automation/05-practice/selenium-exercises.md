# Selenium and TestNG Exercises

1. Start Chrome through a `WebDriver` reference and guarantee `quit()` in cleanup.
2. Automate login with stable `By` locators and a business-result assertion.
3. Replace `Thread.sleep()` with an explicit expected condition.
4. Interact with an element inside an iframe and return to the default content.
5. Open a second window, switch to it, validate its content, and close it safely.
6. Use TestNG setup, teardown, and a data provider without making tests order-dependent.
7. Run the suite in CI and publish its report and failure screenshot.

## Review checkpoint

Explain the difference between the `WebDriver` interface, a browser-driver implementation, a WebDriver session, a TestNG test lifecycle, and an explicit wait.
