## Consolidated interview prompts

- Why is explicit waiting preferable to fixed sleeping?
- How does a WebDriver client communicate with a browser driver?
- How do encapsulation and composition improve automation code?
- What causes an unresolved or rejected promise, and how does `async`/`await` help?
- How would you organize Git branches and pull-request checks for test code?
- How do you distinguish a product failure from an automation or environment failure?
