## Remember the four ideas

- **Encapsulation:** keep data and related behavior together.
- **Inheritance:** reuse behavior from a parent class when there is a true “is-a” relationship.
- **Polymorphism:** use one interface with different implementations.
- **Abstraction:** expose what a caller needs and hide unnecessary detail.

Prefer composition over deep inheritance in test frameworks because smaller objects are easier to change and test.
