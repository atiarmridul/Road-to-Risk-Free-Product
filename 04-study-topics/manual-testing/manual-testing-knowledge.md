# Manual Testing Learning Guide

Manual testing means a person explores and checks software without relying only on automated scripts. The tester observes behavior, compares it with expectations, and reports useful evidence.

## Learning order

1. [Defects, verification, and validation](defects-verification-and-validation.md)
2. [Test design and requirement traceability](test-design-and-rtm.md)
3. [Coverage, QA, and QC concepts](coverage-and-quality-concepts.md)
4. [Release and defect management](release-and-defect-management.md)
5. [PDF resource notes](pdf-resource-notes.md)

Start by understanding the requirement. Design positive, negative, boundary, and exploratory checks. Record the actual result and evidence clearly enough that another person can reproduce the problem.
