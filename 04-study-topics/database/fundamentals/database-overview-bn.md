# SQA ইঞ্জিনিয়ারদের জন্য ডাটাবেস টেস্টিং ওভারভিউ

> **বাংলা সংস্করণ:** এই নোটটি ডেটাবেস টেস্টিংয়ের মূল ধারণাগুলো বাংলায় ব্যাখ্যা করে। ইংরেজি সংস্করণের জন্য [Database Testing Overview](database-overview.md) দেখুন।


## কেন এই ব্যাপার

UI এবং API সফলতা ফেরত দিতে পারে যখন ডেটা এখনও স্টোরেজে ভুল থাকে। ডেটাবেস পরীক্ষা নীরব ডেটা দুর্নীতি, পুনর্মিলন ব্যর্থতা, রিপোর্টিং ত্রুটি এবং আর্থিক অসঙ্গতি প্রতিরোধ করে।

## QA উদ্দেশ্য

1. প্রতিটি ব্যবসায়িক কর্মের পরে ডেটা অখণ্ডতা যাচাই করুন৷
2. সম্পর্কিত টেবিল এবং পরিষেবা জুড়ে ধারাবাহিকতা যাচাই করুন।
3. লেনদেনের নিরাপত্তা এবং রোলব্যাক আচরণ যাচাই করুন।
4. প্রকাশের আগে স্কিমা-পরিবর্তন নিরাপত্তা যাচাই করুন।
5. সংবেদনশীল ডেটা অ্যাক্সেসের নিরাপত্তা নিয়ন্ত্রণগুলি যাচাই করুন৷

## একটি সাধারণ পণ্যের সুযোগ

- OLTP অ্যাপ্লিকেশন টেবিল (ব্যবহারকারী, অর্ডার, অর্থপ্রদান, তালিকা)
- পটভূমি কাজের পার্শ্ব-প্রতিক্রিয়া (পুনরায় চেষ্টা, মৃত চিঠি পুনরুদ্ধার)
- অডিট এবং ইতিহাস টেবিল
- রিপোর্টিং/বিশ্লেষণ হ্যান্ডঅফ টেবিল

## কি QA যাচাই করা উচিত

### ডেটা ইন্টিগ্রিটি
- প্রয়োজনীয় ক্ষেত্রগুলি সঠিকভাবে স্থায়ী হয়৷
- কোন অবৈধ enum/স্টেট মান সংরক্ষণ করা হয় না।
- প্রাথমিক কী এবং অনন্য কী নিয়মগুলিকে সম্মান করা হয়।

### ডেটা সামঞ্জস্য
- API প্রতিক্রিয়া মানগুলি সঞ্চিত মানগুলির সাথে মেলে।
- পিতা-মাতা-সন্তানের সম্পর্কের ধারাবাহিকতা বজায় থাকে।
- ক্রস-সার্ভিস আপডেটগুলি সিঙ্ক্রোনাইজ থাকে৷

### লেনদেনের নির্ভরযোগ্যতা
- মাল্টি-স্টেপ অপারেশন পারমাণবিক।
- আংশিক ব্যর্থতা অবশিষ্ট লেখা ছেড়ে না.
- পুনঃপ্রচেষ্টা সদৃশ ব্যবসার রেকর্ড তৈরি করে না।

### নিরাপত্তা পরিবর্তন করুন
- মাইগ্রেশন পুরানো ডেটা পঠনযোগ্যতা সংরক্ষণ করে।
- ব্যাকফিল/ডিফল্ট স্ক্রিপ্ট প্রত্যাশিত ডেটা তৈরি করে।
- রোলব্যাক প্ল্যানটি স্টেজিংয়ে যাচাই করা হয়।

## প্রবেশ এবং প্রস্থানের মানদণ্ড (রিলিজ-ভিত্তিক)

প্রবেশের মানদণ্ড:
- স্টেজিং এ স্থিতিশীল স্কিমা সংস্করণ
- কী ওয়ার্কফ্লোগুলির জন্য ডেটা বীজ পরীক্ষা করুন
- QA এর জন্য DB পড়ার অ্যাক্সেস (সর্বনিম্ন)

প্রস্থানের মানদণ্ড:
- জটিল ব্যবসায়িক পরিস্থিতি DB প্রমাণ সহ পাস করে
- কোন খোলা Sev-1/Sev-2 DB ত্রুটি নেই
- মাইগ্রেশন যাচাইকরণ সাইন অফ
- পরিচিত DB ঝুঁকি মালিক এবং ETA এর সাথে নথিভুক্ত

## ডিবি পরীক্ষার মাধ্যমে সাধারণ ত্রুটি পাওয়া গেছে

- ভুল মোট কারণ আইটেম-স্তরের রেকর্ড অনুপস্থিত
- সফ্ট-মুছে ফেলা সারি এখনও তালিকা/রিপোর্ট API-এ দৃশ্যমান
- রেসের অবস্থার কারণে ডুপ্লিকেট লেনদেন সারি হয়
- পেমেন্ট সারি প্রতিশ্রুতিবদ্ধ কিন্তু চালান সারি অনুপস্থিত
